### Variables:

| Syntax            | Description                                                   | Default value |
|-------------------|---------------------------------------------------------------|---------------|
| repo_name         | Human-readable name of the repo, i.e. `grafana`               |               |
| repo_url          | URL to the repo, i.e. `https://grafana.github.io/helm-charts` |               |
| update_repo_cache | Should local Helm repo cache be updated?                      | false         |
