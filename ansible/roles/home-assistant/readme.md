### Variables:

| Syntax                   | Description                                                                                                  | Default value         |
|--------------------------|--------------------------------------------------------------------------------------------------------------|-----------------------|
| home_assistant_port      | HTTP port of the Home Assistant Web UI                                                                       | 8123                  |
| home_assistant_root_dir  | Root directory on the host machine                                                                           | `/mnt/home-assistant` |
| home_assistant_image_tag | Docker image tag of the app, i.e. `@sha256:de25f0ad773b54d1c0e5a63147e23417055f3056b0ef24cf4a5ac8019bb33df3` | false                 |
