### Variables:

| Syntax                   | Description                                                                                                                 |
|--------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| http_port                | HTTP port of the Home Assistant Web UI                                                                                      |
| image_tag                | Docker image tag of the app, i.e. `@sha256:de25f0ad773b54d1c0e5a63147e23417055f3056b0ef24cf4a5ac8019bb33df3` or `v0.107.54` |
| root_dir                 | Root directory on the host machine                                                                                          |
